# 🤖 Neon Genesis Evangelion 2 - English Translation Patch
Welcome to the English fan translation project for Neon Genesis Evangelion 2! This project aims to bring the full, immersive Evangelion simulation and story experience to English-speaking fans.

📊 Current Status
The patch is heavily in development, but a huge portion of the core experience is already complete!

✅ Main Story & Character Dialogue: 100% Translated and implemented!

🚧 Combat Dialogue: Work in progress

🚧 Interactable UI & Menus: Work in progress

🎯 Roadmap & What's Next
Right now, the primary focus is making the gameplay systems completely navigable for English players. The upcoming milestones include:

Translating and formatting all mid-battle dialogue and system barks.

Localizing all interactable menus, status screens, and item descriptions.

Extensive QA playtesting to ensure all text fits the native text boxes and reads naturally.
